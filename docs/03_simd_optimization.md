# 专题三：从标量到向量 —— SIMD 在访存密集型算子中的边界探索

**核心价值**：展示对指令级并行（ILP）和现代编译器优化行为的深度洞察。

## 1. 挑战：带宽饱和下的二次优化

在专题二中，通过 Profiling 定位到了 Memory-bound 瓶颈，并优化了 OpenMP 并行策略。但随之而来的问题是：**在内存带宽已经达到物理“天花板”的情况下，继续压榨计算指令是否还有意义？​**

## 2. 实现：编译器引导的 AVX2 向量化

放弃难以维护且容易出错的手写 Intrinsics 指令，转而采用更具可维护性的**编译器引导优化（Auto-vectorization）​**。

**关键优化手段**：
*   **消除内存别名 (Aliasing)​**：使用 `__restrict__` 关键字，明确告知编译器指针之间没有重叠，允许指令重排。
*   **消除循环依赖**：添加 `#pragma GCC ivdep`，显式告知编译器忽略循环内的潜在内存依赖。
*   **编译指令**：在 CMake 中开启 `-mavx2 -march=native -ffast-math`，利用 i9 处理器的硬件特性。

**反汇编验证**：
通过 `objdump` 查看生成的汇编代码，确认核心循环中出现了 `vaddpd` 和 `vmulpd` 等 **256 位宽的 AVX 指令**，证明编译器已成功将标量指令升级为向量指令。

## 3. 实验结论：为什么 SIMD 依然有效？

即便在 Memory-bound 状态下，SIMD 依然带来了 **1.68x** 的性能提升。

**原理解析**：
*   **降低指令流密度 (Instruction Density)​**：单条指令处理 4 个双精度浮点数，意味着 CPU 前端的取指、译码和重命名单元的负载直接降低了 75%。
*   **协同效应**：SIMD 显著缩短了核心逻辑的执行周期，这释放了更多的 CPU 周期用于执行**乱序执行（Out-of-Order Execution）​**和更积极的内存预取，从而在不增加内存带宽的前提下，更有效地“填满”了总线的空隙。
